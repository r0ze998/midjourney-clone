## 2. デザイン

方向は確認のうえで決定: MATRIX の世界観を保つ／顔はロゴの立体／WebGL 可／1画面の名刺。

- **地と光**: 漆黒（#040604）に骨白の文字。緑（#3ef08c）は「信号」としてだけ使う: 背景の雨、状態の点、リンクの反応、立体のリムライト。面や枠は作らず、罫線と余白と光で区切る。
- **顔**: ロゴ（円錐と輪）を three.js で立体化。黒いクリアコート素材に、背後左から緑のリム、前上から白いキー。ゆっくり回り、ポインターにわずかに向きを変える。比率はロゴ画像（1080px）から取った（円錐 高さ:底径 ≒ 3.4、輪の外径は底径より少し大きい、隙間は底径の約 0.18）。**ロゴそのものは変えていない**。ヘッダー・OG画像・WebGL 非対応時の代替には既存の PNG を使う。
- **書体**: 社名「雪風」は Zen Old Mincho 900（鋭い現代明朝）。宣言と Wylls の名は同じ書体の 400。ラベル・リンク・会社情報は Geist Mono。本文は Noto Sans JP。いずれも SIL OFL。
- **背景の雨**: canvas に旧サイトの文字列を縦に流す。列を疎らにし、文字が読める速さに落とした。下 50% と左右を暗く落として文字の居場所を作る。
- **スクロール**: 雨と立体は画面に固定。スクロール量を CSS 変数 `--scroll` にして、雨は暗く、立体は右端へ寄って小さく薄くなり、透かしになる（`ScrollVar.tsx`）。
- **動きを減らす設定**: 雨も立体も動かさず、1フレームだけ描く。JS 無効・WebGL 不可のときはロゴ PNG に置き換わる。
- **旧サイトからの引き継ぎ**: 黒×緑、等幅のラベル、右端の縦書き "WORLD GAME — NOT WORLD WAR GAME"、背景の文字列。捨てたもの: グリッチ、走査線、マーキー、巨大な筆文字。

## 4. 多言語

`/`（日本語）と `/en`。同じコンポーネントに `src/content/site.ts` の `ja`/`en` を渡すため構成は必ず一致する。言語ごとにルートレイアウトを分け `<html lang>` を出し分け。canonical・hreflang・sitemap の alternates を設定。
