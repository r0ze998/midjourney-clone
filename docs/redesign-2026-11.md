# サイト作り直し（2026年11月）— 「Wylls の世界の模型」

公開されない作業記録。前回（2026-10）の事実確認は `docs/redesign-2026-10.md`。計画の本文は承認済みの計画（A「昼の卓」）に沿う。

## 何を作ったか

- 1ページ。トップに **操作できる模型**（ターンのスライダー1本、層のボタン3つ、読み値、自動ツアー）。
- 模型は画面に固定した背景として全セクションに通り、スクロールで場面（ターン・層・カメラ・沈め具合）が移る。
- セクション：ヒーロー／なぜゲームか（3場面）／Wylls／社名とワールド・ゲーム／開発ログ（GitHub から自動）／会社概要・連絡。日英同じ構成。

## 模型の作り（teardown の作法、three.js の 3D）

2026-11-04 の指示（「three.js で 3D に作り直す」）で、Canvas 2D から 3D に作り直した。地形・村・荷車・箱・塔・国境はすべてコードで組み立てる（画像のタイルは使わない）。

| ファイル | 役割 |
|---|---|
| `src/model/hex.ts` | ヘックスの寸法。Wylls クライアントの `map/table.mjs`・`sprites.mjs` と同じ数（半径 44、潰れ 0.76） |
| `src/model/world.ts` | 見本の世界。seed 1117 で一度だけ作る。人の村 3・AIの村 2・倉庫 2・見張り塔 2・荷車の道 8 本 |
| `src/model/state.ts` | `state(turn)`：荷車の位置と向き、在庫、着いた荷、AIの判断の跡、国境、読み値。純粋関数（乱数・時計なし） |
| `src/model/timeline.ts` | ツアーの台本（32 秒、6 拍）と各セクションの場面。カーソルの動きも時間だけから決まる |
| `src/model/tiers.ts` | 段 2（影あり）／1（30fps、影なし、計器は 1 フレームおき）／0（止めた絵、操作で描き直す）。最初の 60 フレームで下げる |
| `src/model/store.ts` | 描画ループと操作部品が共有する状態 |
| `src/model3d/world3d.ts` | 3D の組み立て（InstancedMesh、平らな陰影）。`update(state)` で荷車・箱の数・国境・強調を合わせる。在庫は箱の数で見える |
| `src/model3d/camera.ts` | 視点 5 つ（全景・交易路・AIの区画・国境＝真上・荷車に乗る）。重みで混ぜる。縦長の画面では引く |
| `src/model3d/console.ts` | 計器（在庫と届いた荷のグラフ、AIの判断の帯、荷の配線図）と、模型の部品を指す札 |
| `src/components/WorldStage.tsx` | 固定の WebGL、スクロール→場面、ツアーの時計、段の自動調整、`?capture` の書き出し口。three.js は後から読み込む |
| `src/components/ModelControls.tsx` | 層と視点のボタン・スライダー・字幕・案内カーソル・計器・読み値・ドラッグで回す操作 |
| `src/components/Rain.tsx` | 背景の文字の雨（ご指示で復活）。`?capture` では乱数を固定し、書き出す側が 1 コマずつ進める |

- 入力は `turn` 一つ。画面の数字・グラフ・箱の数・札の文字は、すべて同じ `state(turn)` から出るので、絵と数字が食い違わない。
- 自動ツアー：カーソルがボタンを押して層と視点を切り替える。触ると操作を渡し、25 秒触らなければ戻る。
- 模型の中の文字は英語（ご指示）。字幕はサイトの言語。
- 注記「コンセプトを伝えるための模型で…」と案内文「自動で案内しています…」は、持ち主の指示（2026-11-04）で外した。
- マスの上面は面取りした六角形（中心を少し持ち上げ、面ごとに色をゆらす）。側面は地層の濃淡。地形ごとに飾り（幹のある針葉樹・広葉樹、草、花、畑の畝、岩、丘、峰 3 つの山）。水面はマスいっぱいに張って隣とつなげ、陸に面した辺だけに浜と浅瀬を置く。段 1 以下では飾りを減らす。道の通るマスには畑・花を置かない。
- 霧はカメラから注視点までの距離に合わせる（スマホで引いたとき模型が沈まないように）。

## 映像（X 投稿用）

- `film/timeline.mts` が台本と、荷の到着・AIの判断の時刻を `film/timeline.json` に書き出す。
- 映像は `?capture` のページで `__ykCapture.render(t)` を 1 コマずつ呼んで撮る（1600×900 を 1.2 倍＝1920×1080、60fps、32 秒）。
- 音は `film/score.py`（teardown の sfx、Python 標準ライブラリだけで合成）。時刻はすべて台本から読む。−14 LUFS、ピーク −2 dBFS。
- 書き出したものは `film/out/`（git に入れない）。

## 計測（このセッションのヘッドレス Chromium、GPU なし＝ソフトウェアの WebGL）

- 転送量（圧縮後の見積もり）：約 0.8MB。
  - 最初に読む JS 161KB（gzip）、three.js などの後読み 184KB（gzip）、フォント 394KB、CSS・HTML・画像 約 70KB。
  - 展開後の合計は 1.74MB（JS 1,098KB）。teardown の「1MB 以内」は圧縮後で満たす。
- First Load JS：121 kB（next build の表示）。
- 描画の速さ：GPU のない環境では 1 コマ 0.2〜0.5 秒かかり、実機の値ではない。
  - 段の自動調整は、最初のフレームの実際の間隔で測る（描画の呼び出しだけを測ると GPU の仕事が入らず、下がらなかったので直した）。
  - この環境では約 3 秒で止めた絵の段に下がり、スクロール後の描き直しは 1 回 0.2 秒前後。
- 6 幅（360〜1920）× 日英で横スクロールなし。見出しの順・Tab の順・スライダーのキー操作・25 秒で自動ツアーに戻ること・動きを減らす設定・JS 無効・404 を確認。コンソールのエラーは意図した 404 だけ。
- 映像：1920×1080、60fps、32 秒、15.5MB（H.264＋AAC、faststart）。4 区間に分けて撮り、つなぎ目（8・16・24 秒）で絵が続くことを確かめた。
- サイト用の荷車の映像：1280×720、30fps、4.5 秒、618KB。

## 建物と荷車の作り直し（2026-11-05）

`src/model3d/props.ts` に、建物と荷車の形をまとめた（部品の形と色を一つの形にし、頂点の色で塗る。同じ形はインスタンスで置く）。

- 人の村：漆喰と木の帯の家（切妻屋根・ひさし・棟・煙突・戸口）、草葺きの長屋、二階建ての集会所と角の小塔。窓は別の光る材質で灯る。広場・井戸・市場の屋台・干し草・村人。町（Lamar）は胸壁のある石垣で囲み、道の出る向きに門の塔。風車は羽根がターンで回る。
- AIの村：六角の住まいに紫に光る帯、都市（Verde）の中心に光る核のある尖塔と、浮かんで回る輪。受ける板とアンテナ。人の村とひと目で違う形にした。
- 倉庫：板張りの納屋、大きな戸、荷を積む台、荷を吊る腕木、樽。在庫の木箱は小さくし（建物を隠さないよう）、帯で板の継ぎ目を見せた。
- 見張り塔：石積みの帯、胸壁、とんがり屋根、旗。
- 荷車：人の荷車は、牛（胴・こぶ・首・頭・耳・角・鼻先・尾・脚）が引く四輪の荷馬車と、座った御者。AIの荷車は動物も人もいない、自分で走る車（車輪の覆い、光る帯、感知の柱）。荷は種類で形が違う（食料＝幌の下の袋、木材＝丸太、鉱石＝石。AIの荷車は荷の種類の色の帯の箱）。
- 動き：車輪は進んだ距離だけ回り、牛は歩く。どれも位置と向きだけから決まる（前のフレームを使わない）。
- 家は、道の出る向きと在庫の箱を積む場所を空けて並べ、風車は道と家からいちばん離れた向きに置く。
- 光る窓や帯も、場面で模型を沈めるときは一緒に暗くする。
- Wylls の欄の荷車の映像・OG 画像・止めた絵を、新しい形で撮り直した。

## 社名の項の球体（2026-11-05）

持ち主から受け取った素材「Yukikaze World Game Asset」（Canvas 2D の単体ページ、iframe で埋める前提）を、そのまま貼らずに three.js で作り直してサイトに組み込んだ。

- 素材から使ったもの：大陸の手描きの輪郭（14 の多角形）、6 集落の位置、6 本の循環路、物流の規則（各 50・合計 300、1 便 5 単位、30 秒周期、出発で減り到着で増える）。`src/model/globe.ts`。
- 作り直したもの（`src/model3d/globe3d.ts`、`src/components/WorldGlobe.tsx`）：
  - 地形：細かい正二十面体を、陸は持ち上げ、海は沈める。ヘックスの模型と同じ平らな陰影と同じ地形の色。乾いた帯・森・山・雪・浜。
  - 水面は暗く沈めて少し透かし、浅瀬が見える。大気は縁だけ淡く光る。緯線・経線はごく薄く。
  - 光は月明かり（左上の手前から）。右の縁は暗く落とす。
  - 集落：家の群れと灯り。在庫は箱の数（1 箱 5 単位）。荷は大円の弧の上を時刻どおりに動き、後ろに短い光の尾。
  - 札は模型のコールアウトと同じ形（集落の番号・名前・在庫。英語）。数（保管・輸送中・合計 300）は同じ状態から出す。
  - 操作：自動でゆっくり回る。ドラッグ（スマホは横だけ。縦はページのスクロール）、矢印キー、集落 I〜VI のボタン。25 秒触らなければ自動に戻る。
- 誤解されないように：地形は手描きの模式図で、集落・道・物資量は仮の表現。Wylls の地図はヘックスで、国は 6 つで固定（`wylls/docs/design/redesign/27-design-v1.ja.md` の 3 章）だが、この球体は Wylls のゲーム画面ではない。セクションに「ワールド・ゲームの考え方を描いた模式図です。地形・集落・物流は、実際の地理や Wylls のゲーム内容ではありません。」と添えた。
- 素材の文言（「ひとつの世界。無数の意志。」、集落ごとの説明文、日本語の集落名）は使っていない。サイトの文章・模型の英語表示の決まりに合わせた。素材の画像・動画は使っていない。
- 負荷：
  - 画面に 900px 近づいてから読み込み、見えている間だけ描く。three.js は上の模型と共有。
  - 球体が画面の 3 割以上に出ている間は、後ろの盤を描かない。盤は沈めきって消す。
  - 重い端末（10 フレームの平均が 50ms を超える、コア 2 以下、メモリ 2GB 以下）と、動きを減らす設定では、止めた絵になる。ボタンや操作で描き直す。
  - 読み込むまで・描けないときは、球体から書き出した透過の静止画（`public/media/globe-still.webp`、75KB）を出す。
